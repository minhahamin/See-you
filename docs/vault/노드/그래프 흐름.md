# 그래프 흐름 (backend/agent/graph.py)

START → [[parse_request]]
- 조건 부족 → [[ask_clarification]] → [[parse_request]]
- 충분 → [[search_places]] → [[analyze_reviews]] → [[check_weather]] → [[build_itinerary]] → [[validate_itinerary]]
- 검증 결과에 따라 [[repair_itinerary]] / [[build_itinerary]] / [[present_itinerary]]
- [[repair_itinerary]] → [[validate_itinerary]]
- [[present_itinerary]] → 피드백 있으면 [[apply_feedback]], 없으면 END
- [[apply_feedback]] → [[search_places]] / [[validate_itinerary]] / END

분기 함수는 graph.py에 모은다: route_after_parse, route_after_validate, route_after_present, route_after_feedback.
상태 저장: [[인메모리 체크포인터]]. 재생성 대신 고치는 방식: [[부분 수리]].
